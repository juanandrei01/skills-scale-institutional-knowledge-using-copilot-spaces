# OctoAcme Project Management Docs

## Project Management Processes Summary

OctoAcme uses an iterative, stakeholder-driven approach to project management, emphasizing customer-first thinking, clear ownership, and data-informed decisions. The project lifecycle consists of five core phases:

1. **Initiation**: Validate business need, align stakeholders, and create a lightweight plan with success metrics
2. **Planning**: Break work into shippable increments, identify dependencies and risks, and establish release timelines
3. **Execution & Tracking**: Manage day-to-day delivery with standups, PR workflows, quality gates, and blocker escalation
4. **Release & Deployment**: Standardize releases with pre-deployment checks, smoke tests, and rollback procedures
5. **Retrospective & Continuous Improvement**: Capture learnings and convert them into actionable improvements

**Core Roles**: Project Manager (delivery/risk), Product Manager (vision/priorities), Developers (implementation), QA/Testing (quality validation), and Stakeholders (input/approvals).

For detailed guidance on each phase, see the process documentation index below.
